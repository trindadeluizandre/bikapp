BikeApp — Plataforma Logística Exclusiva Modal Bicicleta

Sistema hyperlocal de entregas rápidas e leves (farmácias, lanches compactos e conveniência), projetado exclusivamente para ciclistas, com cálculo de rota adequado ao modal, remuneração integral sem subprecificação de múltiplas paradas, adicional por espera excedente e ranking semanal premiado em dinheiro.

Estrutura do Projeto

- `apps/backend`: API REST, motor de regras de negócio, cálculo de frete/espera e ranking semanal.
- `apps/web-lojista`: Interface web para comércios parceiros solicitarem entregas leves.
- `apps/mobile`: Aplicativo do entregador (Android/iOS).
- `docs/DOCUMENTO_MESTRE.md`: Roteiro completo de execução e gatilhos de contexto.
